# v0.3.71

- macOS v0.3.71 build 78，Universal 2，支持 Apple Silicon 和 Intel。
- Windows 本次继续提供 v0.3.68，支持 64 位 Windows 10/11。
- Android 本次继续提供已验证的 v0.3.61。
- 修复后台页面已经登录，但客户端总览仍长期显示“需登录”的问题。客户端现在会在同页地址变化、加载结束和切换后台标签时重新核对当前页面会话。
- 隐藏后台释放内存后，新的 WebView 会继续监听页面变化；内存回收过渡页不会被当作业务页。
- 恢复监控前仍检查注销标记、页面 Token 和账号一致性。真正退出、账号冲突或账号不匹配时不会使用旧 Token 查询。

## 验证

- 完整项目测试、macOS Universal 构建、签名及本地 OCR/TOTP 自动化自检通过。
- 真实 WebKit 回归覆盖同文档登录跳转、注销后旧 Token 阻断及隐藏页面恢复。
- 共享 Mac 安装后，`BIllS3` 的监控状态由“需登录”恢复为“正常 77%”，下一轮更新为“正常 75.7%”。安装重启了客户端；同页跳转的触发路径由 WebKit 回归验证。
- GitHub Actions 会重新构建并自检 Windows 包，Release 附件提供 SHA256 校验清单。

## macOS 首次打开

当前包使用内部临时签名，尚未使用 Apple Developer ID 签名和公证。从 GitHub 下载后若出现“Apple 无法验证”提示，请先将应用放入“应用程序”并尝试打开一次，然后进入“系统设置”→“隐私与安全性”→“安全性”，在 SMS Success Monitor 提示旁点击“仍要打开”，输入本机登录密码并再次确认“打开”。
