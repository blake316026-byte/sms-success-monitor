## 三端下载

- macOS：v0.3.57 build 64，Universal 2，支持 Apple Silicon 和 Intel。
- Windows：v0.3.57，64 位 Windows 10/11，完整解压 ZIP 后运行。
- Android：本次未更新，继续使用 v0.3.53 versionCode 53。

## 本次修复

- macOS：将天成页面自动登录与短信、财务监控生命周期拆开。用户关闭某个平台的监控后，当前打开的天成页面仍可使用本机保存的账号密码自动登录。
- macOS：停用监控的平台继续保持零短信查询、零财务查询、零 NPG 会话恢复和零报警；离开该停用页面后停止其登录检测，避免后台页面继续占用资源。
- Windows：将清除缓存入口随 v0.3.57 正式重新打包。橡皮擦按钮位于刷新按钮右侧，可清除网页缓存、代码缓存、Service Worker 和 Cache Storage，并从源站重新加载。
- Windows：清除缓存不删除 Cookie、Local Storage、IndexedDB、本机账号密码或客户端配置，避免清理后丢失登录状态。

## 验证与边界

- 核心、短信、财务、账号隔离、权限检查、退出会话、原生 WebKit、天成登录、平台路由、工作区加载及 Windows 共享回归全部通过。
- 本机 macOS 已在原有监控开关配置下验证：停用监控的天成页面可使用保存账号进入后台首页，页面仍显示监控已停用。
- Windows 正式 ZIP 已拆包验证版本号、工具栏按钮顺序、渲染进程点击事件、预加载桥接和主进程缓存清理处理器；未在 Windows 真机执行本次验收。
- Android 本次未修改，复用 v0.3.53 安装包。
- 发布包不包含本机后台清单、账号密码、Token、Cookie 或 Google 密钥。

各包 SHA-256 见 `SHA256SUMS.txt`。macOS 为内部签名、未公证分发包，首次运行可能提示来源。
