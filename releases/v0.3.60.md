# v0.3.60

- macOS：v0.3.60 build 67，Universal 2，支持 Apple Silicon 和 Intel。
- Windows：v0.3.60，64 位 Windows 10/11，完整解压 ZIP 后运行。
- 同一账号在 `sessionStorage` 与 `localStorage` 中短暂存在新旧 Token 时，优先使用当前会话 Token，不再误判为账号冲突。
- 页面暂时移除再写回 Token 时不再视为注销；Google 验证和 IP 解锁属于登录中间步骤，只有页面确实回到 `/login` 且 Token 仍为空时，才确认退出并作废旧会话。
- 短信或财务接口单次返回鉴权异常时，只刷新当前页面复核一次；网页仍保持登录时停止强制自动登录，避免登录、退出循环。
- 本地验证码识别和登录页脚本增加串行队列与超时恢复，单个平台卡住时不会继续阻塞其他后台的自动登录。
- 保留不同账号会话隔离、主动退出后的旧 Token 作废、权限预检查和自动登录流程。
