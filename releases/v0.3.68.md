# v0.3.68

- macOS v0.3.68 build 75，Universal 2，支持 Apple Silicon 和 Intel。
- Windows v0.3.68，支持 64 位 Windows 10/11。
- Android 本次继续提供已验证的 v0.3.61。
- 优化 macOS 多行平台导航拖动：拖动期间只更新排序预览，松手后一次保存，长距离跨行移动更稳定。
- 优化 macOS 内存：隐藏且空闲的后台网页会释放完整 WebKit 页面，切换回来时使用独立会话恢复。
- 修复页面已经重新登录，但旧退出标记仍让“全部后台”显示“需登录”且不扫描短信的问题。
- 修复同一账号存在新旧多个 Token 时只读取旧 Token、导致短信和财务查询误判登录失效的问题。
- 页面出现不同账号身份时停止自动监控；查询不再使用本机保存 Token 代替网页当前会话，继续保持账号隔离。

## 验证

- 完整项目测试、macOS Universal 构建、签名、压缩包完整性及真实 WKWebView 本地自动化自检通过。
- 共享 MacBook Air 冷启动后，`BIllS02` 实测恢复为“正常”，短信统计成功 181/300、未成功 119，全部后台显示“需登录 0”。
- Windows 共享扫描、财务、权限和会话隔离测试通过；发布工作流会在 Windows 运行打包程序及本地自动化自检。
- GitHub 附件提供 SHA256 校验清单。

## macOS 首次打开

当前包使用内部临时签名，尚未使用 Apple Developer ID 签名和公证。从 GitHub 下载后若出现“Apple 无法验证”提示，请先将应用放入“应用程序”并尝试打开一次，然后进入“系统设置”→“隐私与安全性”→“安全性”，在 SMS Success Monitor 提示旁点击“仍要打开”，输入本机登录密码并再次确认“打开”。正式消除此提示需要配置 Apple Developer ID 证书和 Apple 公证凭据。
