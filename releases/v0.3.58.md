# v0.3.58

- macOS：v0.3.58 build 65，Universal 2，支持 Apple Silicon 和 Intel。
- Windows：v0.3.58，64 位 Windows 10/11，完整解压 ZIP 后运行。
- Android：本次未更新，继续使用 v0.3.53 versionCode 53。

## 修复

- Google 密钥保存前校验：仅接受原始 Base32 密钥或完整 `otpauth://` 链接，无效内容会立即提示，不再停在二次验证页静默重试。
- 登录页和二次验证页产生的临时 Token 不再保存为长期登录 Token，避免页面短暂进入后台后又被接口退回登录。
- macOS 关闭某个平台的监控后，打开该页面仍可使用本机保存的账号自动登录；短信、财务查询和报警继续保持关闭。
- Windows 同步加入 Google 密钥格式校验和认证阶段临时 Token 保护。
- 短信分页在页边界出现重复记录时会继续补取下一页，保证去重后的样本达到用户设置的条数。
