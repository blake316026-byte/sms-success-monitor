# v0.3.62

- macOS v0.3.62 build 69，Universal 2，支持 Apple Silicon 和 Intel。
- Windows、Android 本次没有代码或安装包变更，Release 中继续提供 v0.3.61。
- 网页查找改为高亮当前后台页面中的全部匹配字符，普通匹配显示黄色，当前匹配显示橙色并带下划线。
- 查找栏新增“当前序号/总数”，支持上一个、下一个、Enter、Shift-Enter 循环导航。
- 清空搜索或按 Esc 会立即清除页面高亮；切换后台时在新页面重新查找相同关键词。
- 高亮使用浏览器独立绘制层，不改写后台页面文字节点，避免干扰页面框架渲染。
- Windows 已使用 Chromium 原生查找高亮，本次未修改 Windows 安装包。

## 验证

- 完整回归测试、macOS Universal 构建、签名和压缩包完整性检查通过。
- 打包后的真实 WKWebView 自检确认三处匹配同时进入高亮层，并可从第 1 项切换到第 2 项。
- 本机已安装并启动 macOS v0.3.62 build 69；GitHub 附件提供 SHA256 校验清单。

## macOS 首次打开

当前包使用内部临时签名，尚未使用 Apple Developer ID 签名和公证。从 GitHub 下载后若出现“Apple 无法验证”提示，请先将应用放入“应用程序”并尝试打开一次，然后进入“系统设置”→“隐私与安全性”→“安全性”，在 SMS Success Monitor 提示旁点击“仍要打开”，输入本机登录密码并再次确认“打开”。正式消除此提示需要配置 Apple Developer ID 证书和 Apple 公证凭据。
