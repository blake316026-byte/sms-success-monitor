# v0.3.62

- macOS v0.3.62 build 69，Universal 2；当前为本地候选版本，尚未发布 GitHub Release。
- 网页查找改为高亮当前后台页面中的全部匹配字符，普通匹配显示黄色，当前匹配显示橙色并带下划线。
- 查找栏新增“当前序号/总数”，支持上一个、下一个、Enter、Shift-Enter 循环导航。
- 清空搜索或按 Esc 会立即清除页面高亮；切换后台时在新页面重新查找相同关键词。
- 高亮使用浏览器独立绘制层，不改写后台页面文字节点，避免干扰页面框架渲染。
- Windows 已使用 Chromium 原生查找高亮，本次未修改 Windows 安装包。
