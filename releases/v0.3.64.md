# v0.3.64

- macOS v0.3.64 build 71，Universal 2，支持 Apple Silicon 和 Intel。
- Windows v0.3.64，支持 64 位 Windows 10/11。
- Android 本次未完成新版 APK 编译，Release 继续提供已验证的 v0.3.61。
- 工具栏新增“自动高亮”，可保存多个关键词、启用状态、高亮颜色和完整词匹配设置。
- 关键词设置仅保存在本机，保存后应用到全部后台；刷新页面、切换标签和网页动态加载内容后继续高亮。
- 高亮忽略大小写，并避开输入框、脚本、隐藏和可编辑内容，避免干扰第三方后台操作。
- 当前选中的已保存账号页面会优先启动自动登录，不再等待全部后台的错峰启动队列。

## 使用方法

1. 点击浏览器工具栏中的“自动高亮”图标。
2. 勾选“启用自动高亮”，每行输入一个关键词。
3. 选择颜色；需要严格匹配完整单词或词组时勾选对应选项。
4. 点击“保存”，当前页面和其他后台页面会立即应用。

## macOS 首次打开

当前包使用内部临时签名，尚未使用 Apple Developer ID 签名和公证。从 GitHub 下载后若出现“Apple 无法验证”提示，请先将应用放入“应用程序”并尝试打开一次，然后进入“系统设置”→“隐私与安全性”→“安全性”，在 SMS Success Monitor 提示旁点击“仍要打开”，输入本机登录密码并再次确认“打开”。正式消除此提示需要配置 Apple Developer ID 证书和 Apple 公证凭据。
