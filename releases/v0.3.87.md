# v0.3.87 公开精简版

macOS / Windows 更新，Android 保持 v0.3.85。不加入完整版的监控浮窗、支付/短信通道管理或留存报表等模块。

## 更新
- 修复 macOS 网页“汇入／上传”不弹文件选择框，取消不选择文件。
- 新增提现挂单 TG 报警及平台勾选，默认关闭，默认超过 20 分钟，可调整。
- 同一平台同一订单北京时间每天最多一次，发送不明不自动重发，记录保留 24 小时。
- 已有报警配置升级保留现有平台勾选；新增平台默认不勾选。
- 保留订单创建时间、等待筛选、超时高亮、工作台和提现审核人员查询。

## 数据与升级
不附带开发者后台、账号、密码、密钥、Cookie、TG Token/群 ID 或业务配置；仅保留原精简版示例占位页。
退出原程序后替换程序，保留用户数据目录。原公开版账号、配置、持久登录数据和 TG 当天发送记录沿用。过期或被网站撤销的会话仍需重新认证。
Windows 完整解压，不要只取 EXE，无需 Node.js；macOS 替换 SMS Platform Workbench.app。

## 未签名与系统提示
Windows 未使用商业代码签名；Mac 临时签名、未公证，可能有系统提示。
若 Windows 显示“智能应用控制已阻止可能不安全的应用”，确认来源及 SHA-256 并理解风险后，可由设备所有者在“Windows 安全中心 → 应用和浏览器控制 → 智能应用控制设置”选择“关闭”。
这影响整台电脑，不是单应用放行；不要关闭 Defender 实时保护或防火墙。能否重新开启以本机提示为准，旧系统可能需要重置。组织设备联系管理员。客户端不会修改安全设置。
[详细说明及微软链接](https://github.com/blake316026-byte/sms-success-monitor/blob/main/WINDOWS.md)。

SHA256SUMS.txt 提供包校验值。不会上传业务文件、处理订单或发送测试 TG 消息。
