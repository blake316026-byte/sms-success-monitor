- Windows：v0.3.53，64 位 Windows 10/11，完整解压 ZIP 后运行。

## 本次修复

- macOS：全部后台统计表的日常数据更新只更新现有单元格，不再重载整张表、重新选中行或主动调整滚动位置；平台清单变化时按系统实际滚动边界保留位置，修复顶部向下偏移、底部向上偏移的问题。
- macOS：修复退出后重新登录只恢复短信查询、遗漏财务定时任务的问题。登录完成及短信恢复后补齐财务任务，继续按 20 秒间隔刷新，避免重复创建任务。
- 监控关闭、登录失效和财务权限限制仍然有效；没有增加接口探测或放宽报表授权。
- Windows、Android 本次同步版本并重新打包，保留 v0.3.52 的账号隔离和权限检查；上述原生滚动及财务调度修复仅针对 macOS。

## 验证与边界

- macOS 原生表格回归覆盖顶部、中间、底部及两种滚动条样式，连续更新保持滚动位置与选中平台；财务任务恢复接线、核心、共享脚本及 WebKit 会话回归通过。
- 本机 macOS 已实测顶部和底部跨自然数据刷新保持不动，BIllS01 充值、提现及充提差恢复，并在短信未更新时独立刷新财务数据。
- 三端构建与打包校验通过；Windows、Android 本次未进行真实业务账号完整登录验收。

发布包不包含本机后台清单、账号密码、Token、Cookie 或 Google 密钥。各包 SHA-256 见 `SHA256SUMS.txt`。macOS、Windows 为内部签名或未公证分发包，首次运行可能提示来源；Android 使用当前项目的调试签名，需允许安装该来源应用。
