## 下载版本

- macOS：v0.3.56 build 63，Universal 2，支持 Apple Silicon 和 Intel。
- Windows：本次未更新，继续使用 v0.3.53。
- Android：本次未更新，继续使用 v0.3.53 versionCode 53。

## 本次修复

- macOS：允许用户配置的 HTTP 后台在 WebView 内加载脚本和样式，修复正式应用受 ATS 限制后只显示空白页面的问题；客户端原生网络请求仍受 ATS 保护。
- macOS：未知自定义域名改为仅浏览模式，不调用 NPG 短信及财务查询，也不触发扫描报警或失败重载。已接入的 NPG、OKBET 和天成页面继续使用独立路由。
- macOS：恢复工作区时，自定义页面改为选中或启动监控后按需加载，避免多个大型后台同时下载造成白屏和卡顿。
- macOS：NPG Token 失效或退出后，可在登录页账号与本机保存账号一致时恢复账号密码、图形验证码及 Google 二次验证自动登录；账号不一致时仍停止自动登录，不复用旧 Token。
- macOS：新增天成后台密码模式切换、账号密码提交及 Google 二次验证自动登录。天成目前仅接入登录，不调用 NPG 短信或财务接口。

## 验证与边界

- 核心、短信、财务、账号隔离、权限检查、退出会话、原生 WebKit、天成登录、平台路由、工作区按需加载和 Windows 共享脚本测试全部通过。
- macOS Universal 2 安装包已在本机安装；真实 HTTP TCG 后台已显示登录页并完成站点内部跳转。
- 本次没有更新 Windows 和 Android 安装包，也没有对这两端声明上述 macOS 原生功能已接入。
- 发布包不包含本机后台清单、账号密码、Token、Cookie 或 Google 密钥。

安装包 SHA-256 见 `SHA256SUMS.txt`。macOS 为内部签名、未公证分发包，首次运行可能提示来源。
