# v0.3.83 公开精简版

- macOS、Windows、Android 完整移除“全部后台/国家总计”、监控浮窗及其菜单、报警入口。
- 关闭短信与充提统计的定时采集；保留后台工作台、本地登录配置和网页高亮。
- macOS 保留全平台待处理订单、提现审核人员查询、原页面复用、筛选后服务器总条数、一天缓存及自动补查。
- Windows、Android 暂不包含 macOS 的订单聚合和审核人员查询页面。
- 独立应用标识和本地数据目录，不自动导入或覆盖完整版的配置、凭据、会话和缓存。
- 不内置真实后台、账号或业务数据；需要自行配置平台并登录。

macOS：v0.3.83 build 104，Universal 2。Windows：v0.3.83，x64。Android：v0.3.83 versionCode 104。
