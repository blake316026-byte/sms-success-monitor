# v0.3.61

- macOS v0.3.61 build 68，Universal 2，支持 Apple Silicon 和 Intel。
- Windows v0.3.61，64 位 Windows 10/11，完整解压 ZIP 后运行。
- Android v0.3.61 versionCode 61，Android 8.0 及以上；重新构建并包含最新共享登录、短信和财务脚本。

## macOS 登录循环修复

- 修复认证恢复标记未清除：不再在加载首页 `/` 的导航完成回调中取消登录确认，确认业务页面和当前配置账号的会话后才清除重新认证标记并恢复监控。
- 登录确认时更新会话代次，旧登录和查询回调不得修改新会话。
- Google 验证和加载首页期间不发起短信、财务查询；加载超时暂停，不重新提交账号密码。
- 共用登录脚本增加动画帧等待上限，后台标签暂停绘制时也能继续提交表单。
- 增加直接执行实际 Swift 状态转换方法的无网络回归测试，覆盖认证恢复、二次验证、会话缺失、迟到回调和加载超时。

## 包含此前未发布的修复

- macOS、Windows 不再用保存的旧 Token 构造不完整网页会话查询；认证中间阶段的临时 Token 不保存为长期会话。
- 共享查询优先使用当前 sessionStorage；同账号短暂的新旧 Token 不再误判为账号冲突，仍禁止不同账号混用及无权限查询。
- macOS、Windows 对接口鉴权异常先刷新页面复核，不因单次接口失败反复强制登录。
- macOS 延迟确认 Token 清除，兼容 Token 轮换、Google 验证和 IP 解锁；本地验证码运行时加入串行队列与超时恢复。
- 修复停用监控页面和单页应用跳转后的自动登录、Google 验证续接；监控关闭后仍不查询、不报警。
- Google 密钥保存时校验格式，短信分页遇到重复记录继续补取样本。

## 验证边界

- 本机完整回归测试、macOS Universal 打包自检及新版 cg04、cg12 登录确认通过；cg04 已观察到连续扫描成功。
- 新版主动注销后恢复与刷新全流程尚未完成现场复测；短期扫描结果不代表所有平台长期登录稳定性已验证。
- Windows 包由 GitHub Windows 环境构建并运行打包后自检；Android 完成构建与 lint，未进行真机登录验收。
- 安装包为内部签名版本；SHA256SUMS.txt 用于下载校验。
