# v0.3.86 公开精简版：待处理订单时间与超时高亮

本次仅更新 macOS / Windows 的「全平台待处理订单」，不增加其他模块。

- 新增订单创建时间（北京时间）和等待时长。
- 仍未处理且等待超过 20 分钟的订单以浅红底、红字高亮，顶部显示超时数量。
- 时间缺失或异常、正在刷新或已取消查询的旧结果不误报超时。
- 保留原有订单查询、分页、筛选和点击订单跳转能力，不处理订单、不重试支付或配置操作。

## 下载与升级

- macOS 13+：Apple Silicon / Intel 通用包。
- Windows 10/11 x64：解压后运行程序。
- Android 没有此订单页面，保持 [v0.3.85](https://github.com/blake316026-byte/sms-success-monitor/releases/download/v0.3.85/SMS-Success-Monitor-Android.apk)，本次不重新发布。

## 验证范围

订单创建时间字段、时区、20 分钟边界、无时间/未来时间、查询取消和失败、分页筛选均有自动化用例。Mac 原生窗口和打包运行检查、Windows 打包程序窗口检查使用隔离测试数据，不代表逐个生产后台实测。

macOS 包沿用本项目的本地签名方式，未进行 Apple 公证；Windows 包没有商业代码签名。下载后可用附件 SHA256SUMS.txt 核对文件完整性。
