# v0.3.59

- macOS：v0.3.59 build 66，Universal 2，支持 Apple Silicon 和 Intel。
- Windows：v0.3.59，64 位 Windows 10/11，完整解压 ZIP 后运行。
- Android：本次未更新，继续使用 v0.3.53 versionCode 53。

## 修复

- NPG 页面缺少完整登录会话时，不再用本机保存的旧 Token 直接查询短信或财务接口。
- 移除根据旧 Token 创建仅含 `token` 字段的 `lt-user` 页面会话，避免自动登录后再次退出或在登录页与报表页之间反复跳转。
- `/login`、`/ga-auth`、`/unlock-ip` 统一进入真实认证流程；已保存配置的同一账号会继续执行账号密码、图形验证码和 Google 验证。
- macOS、Windows 与共享扫描脚本同步采用完整页面会话校验。

## 验证

- 核心、短信、财务、账号隔离、退出生命周期、原生 WebKit、天成登录、平台路由、停用平台和 Windows 打包结构检查全部通过。
- Android 本次没有代码或安装包变更。
