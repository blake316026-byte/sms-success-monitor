# v0.3.69

- macOS v0.3.69 build 76，Universal 2，支持 Apple Silicon 和 Intel。
- Windows 本次继续提供 v0.3.68，支持 64 位 Windows 10/11。
- Android 本次继续提供已验证的 v0.3.61。
- 修复 macOS 隐藏后台释放 WebKit 内存后，切换回来地址栏正常但页面内容空白的问题。
- 修复页面恢复与后台回收之间的状态竞争，避免当前页面刚恢复就再次被回收。
- 保留每个平台的独立 Cookie、网页存储和登录会话，不改变短信、财务、权限或自动登录规则。

## 验证

- 完整项目测试、macOS Universal 构建、签名、压缩包完整性及真实 WKWebView 本地自动化自检通过。
- 新增真实 WebKit 回归，确认轻量回收页切回后会加载完整业务文档及页面内容。
- 共享 MacBook Air 安装后，`BIllS4` 实测先完成隐藏回收，再通过平台导航切回；地址栏恢复原业务 URL，网页显示 `BIllS4-PH` 的“报表、工作面板、支付”等真实内容，且未再次立即回收。
- GitHub Actions 会重新执行 Windows 共享扫描、财务、权限、会话隔离、打包和运行时自检；Release 附件提供 SHA256 校验清单。

## macOS 首次打开

当前包使用内部临时签名，尚未使用 Apple Developer ID 签名和公证。从 GitHub 下载后若出现“Apple 无法验证”提示，请先将应用放入“应用程序”并尝试打开一次，然后进入“系统设置”→“隐私与安全性”→“安全性”，在 SMS Success Monitor 提示旁点击“仍要打开”，输入本机登录密码并再次确认“打开”。正式消除此提示需要配置 Apple Developer ID 证书和 Apple 公证凭据。
